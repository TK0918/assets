# 企业后台管理系统

一个现代化的企业级后台管理系统，基于 HTML5、CSS3 和原生 JavaScript 构建。

## 项目结构

```
.
├── index.html              # 主页面（包含侧边栏导航）
├── modules/               # 功能模块目录
│   ├── customer-entity.html    # 客户主体管理
│   ├── transfer-review.html    # 线下转账审核
│   ├── credit-review.html      # 信用额度审核
│   ├── transaction-details.html # 资金明细
│   └── permission-config.html  # 权限配置
└── README.md             # 项目文档
```

## 功能模块

### 1. 客户主体管理
- 管理客户主体信息
- 支持按主体ID、名称、合同编号等筛选
- 提供编辑和查看钱包功能

### 2. 线下转账审核
- 审核客户提交的线下打款记录
- 支持按主体ID、银行流水号等筛选
- 提供通过/驳回操作和日志查看

### 3. 信用额度审核
- 管理客户信用额度申请
- 支持按主体ID、申请日期等筛选
- 提供额度审批和详情查看

### 4. 资金明细
- 展示所有交易流水记录
- 支持多维度筛选和导出
- 提供交易详情查看

### 5. 权限配置
- 基于 RBAC 的权限管理
- 支持页面和按钮级权限控制
- 提供权限变更日志

## 技术特点

- 纯前端实现，无需后端依赖
- 响应式设计，适配不同屏幕尺寸
- 模块化结构，便于维护和扩展
- 统一的视觉风格和交互体验

## 开发规范

### HTML
- 使用语义化标签
- 保持结构清晰
- 添加适当的注释

### CSS
- 使用 CSS 变量管理主题
- 采用 BEM 命名规范
- 模块化样式组织

### JavaScript
- 原生 JS 实现
- 事件委托优化
- 代码模块化

## 使用说明

1. 克隆项目到本地
2. 使用现代浏览器打开 `index.html`
3. 通过侧边栏导航访问各个功能模块

## 浏览器支持

- Chrome (推荐)
- Firefox
- Safari
- Edge

## 注意事项

- 本项目为纯前端演示，实际使用时需要配合后端 API
- 建议使用现代浏览器访问以获得最佳体验
- 部分功能需要后端支持才能完全实现
